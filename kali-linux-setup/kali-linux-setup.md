# Kali Linux Setup 

Hello everyone! Here's a guide on how to get kali linux running on your laptop alongside windows without removing your existing OS. Feel free to reach out if you have any question! 👾

---

### 1. Download VMWare

You might need to create an account and sign in to Broadcom before you can grab the download.

If you're on a Mac, go with VMWare Fusion or VirtualBox instead. Make sure to download the **Personal Use** version!

**Links:**

- VMWare Workstation Pro : [ProductDownloads - Support Portal - Broadcom support portal](https://support.broadcom.com/group/ecx/productdownloads?subfamily=VMware%20Workstation%20Pro&freeDownloads=true)
- VMWare Fusion (for Mac) : [ProductDownloads - Support Portal - Broadcom support portal](https://support.broadcom.com/group/ecx/productdownloads?subfamily=VMware%20Fusion&freeDownloads=true)


Example for Workstation Pro : 

![vmware-1.png](https://github.com/c4ndypop/workshop/blob/main/kali-linux-setup/images/vmware-1.png?raw=true)

---

### 2. Download Kali Linux Image

**Kali Linux Link :** [Get Kali | Kali Linux](https://www.kali.org/get-kali/#kali-virtual-machines)

Be sure to grab the version that's **pre-built for VMWare** okay!

![vmware-2.png](https://github.com/c4ndypop/workshop/blob/main/kali-linux-setup/images/vmware-2.png?raw=true)

> Download the VMWare version (just hit the download icon)

---

### 3. Extract the Kali Linux Files

![vmware-3.png](https://github.com/c4ndypop/workshop/blob/main/kali-linux-setup/images/vmware-3.png?raw=true)

You can use 7zip for this. But if you're able to extract it without any issues using something else, that works too.

**7zip link :** [https://www.7-zip.org/](https://www.7-zip.org/)

---

### 4. Complete the VMWare Installation & Setup

Run the VMWare installer and just follow through the steps as usual. If it prompts you to update, you can skip that for now.

Once VMWare is set up, you should see a screen like this when you open it:

![vmware-4.png](https://github.com/c4ndypop/workshop/blob/main/kali-linux-setup/images/vmware-4.png?raw=true)

---

### 5. Launch Kali Linux

![vmware-5.png](https://github.com/c4ndypop/workshop/blob/main/kali-linux-setup/images/vmware-5.png?raw=true)

- Click **"Open a Virtual Machine"** inside VMWare, then navigate to the folder where your kali linux files are and select the file from there.
- Give it a moment to boot up the kali system inside VMWare. Once it's finished loading, you'll see the login screen.
- Use these credentials to log in:

    **Username :** `kali`

    **Password :** `kali`

![vmware-6.png](https://github.com/c4ndypop/workshop/blob/main/kali-linux-setup/images/vmware-6.png?raw=true)

---
