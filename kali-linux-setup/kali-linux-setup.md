# Kali Linux Setup

Hello everyone! Here's a guide on how to get kali linux running on your laptop alongside windows without removing your existing OS. Feel free to reach out if you have any question!

---

### 1. Download VMWare

You might need to create an account and sign in to Broadcom before you can grab the download.

If you're on a Mac, go with VMWare Fusion or VirtualBox instead.

Make sure to download the **Personal Use** version!

**Links:**

- VMWare Workstation Pro : [ProductDownloads - Support Portal - Broadcom support portal](https://support.broadcom.com/group/ecx/productdownloads?subfamily=VMware%20Workstation%20Pro&freeDownloads=true)
- VMWare Fusion (for Mac) : [ProductDownloads - Support Portal - Broadcom support portal](https://support.broadcom.com/group/ecx/productdownloads?subfamily=VMware%20Fusion&freeDownloads=true)

Example for Workstation Pro : [VMWare Workstation Pro](

### 3. Extract the Kali Linux Files

*[screenshot]*

You can use 7zip for this (that's what I usually go with). But if you're able to extract it without any issues using something else,, that works too.

**7zip link :** [https://www.7-zip.org/](https://www.7-zip.org/)

---

### 4. Complete the VMWare Installation & Setup

Run the VMWare installer and just follow through the steps as usual. If it prompts you to update, you can skip that for now.

Once VMWare is set up, you should see a screen like this when you open it:

*(The look might be a little different since this screenshot is from VMWare Player — we're using the Pro version)*

*[screenshot]*

Ignore the extra files there ya,, those are mine haha

---

### 5. Launch Kali Linux

*[screenshot]*

- Double-click the `.vmdk` file. It should open up in VMWare automatically.
- If that doesn't work, try clicking **"Open a Virtual Machine"** inside VMWare, then navigate to the folder where your kali linux files are and select the file from there.
- Give it a moment to boot up the kali system inside VMWare. Once it's finished loading, you'll see the login screen.
- Use these credentials to log in:

    **Username :** `kali`

    **Password :** `kali`

*[screenshot]*

---

### 6. Alternative Method for Step 5

*[screenshot]*

- Click on **( Open a Virtual Machine )**
- Browse to the folder where you extracted the kali linux files
- Pick the file that shows up
